# Activity 5 Answers
1. What do move(), special_move(), and use() have in common?  
Answer: They are methods with the same name used by different classes. Each class gives its method a different behavior.

2. How does this show polymorphism in a gaming context?  
Answer: The same function can be used with different game characters or items. The action changes depending on which object is passed to the function.

3. What are other examples?  
Answer: Different characters could have an attack() method: one character could swing a sword, while another shoots an arrow. Different items could have an activate() method that gives a shield or restores energy.
