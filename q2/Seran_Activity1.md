1. What is/are the parent class/es of the Programmer class in the video?

 The parent classes of the "Programmer" class are:

   - "Employee" — the direct parent or superclass
   - "Person" — the parent of "Employee" and the base class

   The inheritance hierarchy is:
        Person, Employee, and then Programmer

2. If you were to add a new role called Intern, where would you place it in the inheritance

hierarchy? Why?

 I would place the "Intern" class under the "Employee" class, alongside "Programmer", "Manager", and "Cleaner".

   An intern is a type of employee, so it can inherit the common properties and methods of "Employee". It may also have its own unique properties and methods, such as an internship duration or assigned supervisor.
