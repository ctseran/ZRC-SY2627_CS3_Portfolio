1a. What is duck typing?  
Answer: Duck typing means an object can be used if it has the method the code needs. 
It does not have to inherit from a specific class.

1b. What method does the Car class need?  
Answer: It needs a move() method, since the shared code calls move() for each object. 

3. How does this show polymorphism?  
Answer: The same function calls move() on different objects, and each object does something different.
